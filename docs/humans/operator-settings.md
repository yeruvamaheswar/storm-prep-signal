# Hold and Auto

Hold and Auto are saved in two places. This laptop keeps `var/state.json`. Supabase keeps one `operator_settings` row so the wall on Render and the live worker here share the same choice.

Press Hold on the wall. The next live tick delivers 0. Press Auto and the next tick can charge or sell again from the price bands.

If Supabase is down, the local file still works on the machine that wrote it. The engine never reads the table itself.

More: `docs/agents/operator-settings.md`.
