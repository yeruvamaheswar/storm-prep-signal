# Fleet list

On the wall, click **Fleet** next to ReserveGate. That opens `/fleet` in the same app. If a load zone is selected, the list opens already filtered to that zone. **Wall** goes back to `/`.

The list shows the 100-home demo fleet, not all 10,000 seeded rows. Search is by home id.

More detail: `docs/agents/fleet-scale.md`.
