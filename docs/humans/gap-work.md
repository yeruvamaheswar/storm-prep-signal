# How we pick the next piece of work

We write down the finished product we want. The assistant then names **one** gap between that picture and the repo. We fill that gap. Then we stop and ask for the next one.

Any file that gap needs may change. We do not save files for one person. We do not work two gaps at once.

The finished-product picture is in `docs/agents/reservegate-summarized.md`. What we will not drop is in `docs/agents/team-manifest.md`. The long rule for the assistant is `docs/agents/gap-work.md`.
